## 一、硬件配置（已验证）

### 主控

| 项 | 值 |
|---|---|
| 型号 | STM32F429IGT6 (LQFP176) |
| 主频 | 180 MHz |
| 工具链 | Keil MDK ARMCC 5 (AC5) |
| 驱动方式 | 寄存器级 CMSIS，无 HAL |

### 四块探测器板

| 编号 | 位置 | 丝印范围 | 颗数 | 索引范围 | 方向 |
|---|---|---|---|---|---|
| **E0** | 下长边 | D25 → D4F | **43** | 21 ~ 63 | 左 → 右 |
| **E1** | 右短边 | D35 → D49 | **18** | 22 ~ 39 | 下 → 上 |
| **E2** | 上长边 | D4F → D35 | **42** | 22 ~ 63 **逆序** | 左 → 右 |
| **E3** | 左短边 | D35 → D3A | **21** | 22 ~ 42 | 上 → 下 |

### 索引映射规则

```
索引 i（0~63） →  列 = i / 4（十六进制）
                  行 = i % 4 + 1
              位号 = D{行}{列}
```

**示例：**
- 索引 21 → 列 5、行 2 → **D25**
- 索引 63 → 列 F、行 4 → **D4F**
- 索引 22 → 列 5、行 3 → **D35**

### 引脚分配

#### SPI4（四块板共用）

| 信号 | MCU 引脚 | 物理脚 | 说明 |
|---|---|---|---|
| SPI4_SCK | **PE2** | 1 | AF5 |
| SPI4_MISO | **PE5** | 4 | AF5，四块板 SDO 并联 |
| SPI4_MOSI | **PE6** | 5 | AF5 |

#### 片选 CS（四根独立，绝不可并联）

| 板 | 边 | CS 引脚 | 物理脚 | FPC 座 | CS 网络 |
|---|---|---|---|---|---|
| A | E0 | **PI8** | 7 | FPC12 | SPI4_CS4 |
| B | E1 | **PH4** | 45 | FPC16 | SPI4_CS0 |
| C | E2 | **PC13** | 8 | FPC13 | SPI4_CS3 |
| D | E3 | **PI9** | 11 | FPC14 | SPI4_CS2 |

> **PC13 经 R127（22Ω）串联端接到 FPC13 第 3 脚**

#### 行选 EN（每条 FPC 独立，四组同时驱动）

| 板 | EN1 | EN2 | EN3 | EN4 | FPC 脚 |
|---|---|---|---|---|---|
| **A** | PD13 | PD12 | PH11 | PH10 | FPC12 pin 6-9 |
| **B** | PD7 | PD6 | PD5 | PD4 | FPC16 pin 6-9 |
| **C** | **PG3** | **PG2** | **PD15** | **PD14** | FPC13 pin 6-9 |
| **D** | **PG7** | **PG6** | **PG5** | **PG4** | FPC14 pin 6-9 |

**EN 为高有效，一次只拉高一路（一热码）。**

## 二、关键实现

### ADS7953 命令字

```c
cmd = 0x1000 | ((ch & 0x0F) << 7)
```

- **DI15-DI12 = 0001**：手动模式 + 通道选择
- **DI10-DI07**：通道号 0~15
- **DI06**：量程（0 = 0..VREF）

> ⚠️ **通道地址在 bit10~7，不是 bit15~12。** 写错会落入模式字段，导致芯片进入自动扫描、忽略地址。

### 2 帧流水线

```
第 n 帧：发送"选通道 ch"命令
第 n+1 帧：芯片对该通道采样转换
第 n+2 帧：SDO 上返回结果
```

**所以每行读 18 帧（16 + 2 冲刷），结果落在第 2~17 帧。**

### SPI 参数

| 项 | 值 |
|---|---|
| 数据帧宽 | 16 bit（DFF=1） |
| CPOL / CPHA | 0 / 1 |
| 波特率分频 | BR=7 → 352 kHz |
| 每帧 CS | 独立低脉冲 |

### 四边读取流程

```
第一遍：CS = PI8 / PH4   →  读 E0（板A）+ E1（板B）
第二遍：CS 切到 PC13     →  读 E2（板C）
第三遍：CS 切到 PI9      →  读 E3（板D）
```

> **切换片选前必须把全部 CS 拉高，否则并联 MISO 会总线冲突。**

### 串口命令

| 命令 | 功能 |
|---|---|
| `V` | 版本信息 |
| `K BOTH` | 读 E0 + E1（原有两条边） |
| `K EDGES` | **读全部四条边** |
| `K LONG` / `K SHORT` | 单独读长边 / 短边 |
| `K T6` / `K T7` | 诊断：输出板C / 板A 全部 64 通道 |
| `K CS` | 候选片选扫描 |

**串口参数：115200 8N1，命令以 `\r\n` 结尾。**

## 三、上位机工具

### `tools/edge_check.py` — 四边数据监视

```bash
python tools/edge_check.py COM5
```

**四条边独立显示，每条边包含：**
- 强度波形（Y 轴自动缩放）
- 每颗探测器的丝印标签（D25 / D35 / …）
- 峰值位置标记（红色三角）
- 25% 阈值线
- 右上角：峰值 / 位置 / σ

### `tools/edge_dsp.py` — 信号处理链

**行业标准流程（用于光电二极管阵列 / PSD / 光束轮廓仪）：**

| 步骤 | 方法 | 作用 |
|---|---|---|
| ① 自适应基线 | 20 分位数初始化 + 非对称指数跟踪 | 消除暗电流与偏置 |
| ② 中值滤波 | 3 点 | 剔除单点尖刺、坏探测器 |
| ③ Savitzky-Golay | 5 点二阶 `[-3,12,17,12,-3]/35` | 抑制噪声且不压低峰值 |
| ④ 相对阈值 | 峰值 × 25% | 只保留光斑主瓣 |
| ⑤ 加权重心 | `Σ(vᵢ·i)/Σvᵢ` | 亚探测器定位 |
| ⑥ 高斯拟合 | log-二次最小二乘 | 最高精度，给出光斑宽度 σ |
| ⑦ α-β 滤波 | 位置 + 速度双状态 | 跟踪平滑 |

**实测精度（构造 σ=2.2 高斯峰 + 注入 3000 坏点）：**

| 指标 | 真值 | 结果 | 误差 |
|---|---|---|---|
| 重心 | 20.30 | 20.36 | 0.06 格 |
| 高斯拟合 μ | 20.30 | 20.31 | **0.01 格** |
| 高斯拟合 σ | 2.20 | 2.23 | 0.03 |

## 四、调试过程中修复的重要缺陷

| # | 缺陷 | 修复 |
|---|---|---|
| 1 | `board_delay_us` 用 DWT 周期计数器，但计数器不计数 → **永久死循环** | 改用软件循环 |
| 2 | 栈只有 **1 KB**，跑带 264 字节局部结构体的扫描函数 | 扩到 **8 KB** |
| 3 | 6 处大型结构体分配在栈上 | 全部改 static |
| 4 | 四块板并联 MISO，切换片选时**总线冲突** | 切换前把全部 CS 拉高 |
| 5 | **EN 行选是每条 FPC 独立**的，板 C/D 的 EN 从未驱动 | 补 PG3/PG2/PD15/PD14 与 PG7/PG6/PG5/PG4 |
| 6 | **E2 索引范围错误**（配成 7~22，实际应为 63~22 逆序 42 颗） | 已修正 |

## 六、验证方法

**烧录后串口执行：**

```
K EDGES
```

**应输出四行：**

```
E0:43 <43 个数值>
E1:18 <18 个数值>
E2:42 <42 个数值>
E3:21 <21 个数值>
```

**无光照时四边噪声量级应一致（总和 3~15）。**

**打开激光后，对应边的某一颗（或相邻几颗）数值应升至数千。**
