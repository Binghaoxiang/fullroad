# 四边探测器系统 —— 硬件接线与软件设计

> 屏幕尺寸：**200 mm × 100 mm**（长 20 cm，宽 10 cm）
> 四块裁剪探测器板 + 四块 ADS7953 转接板，SDO 并联共用 MISO

---

## 一、四边定义

```
                    上长边（新增）D35 → D41，右 → 左
        ┌───────────────────────────────────────────────┐
        │                                               │
  左    │                                               │  右
  短    │              200 mm × 100 mm                  │  短
  边    │                                               │  边
（新    │                                               │（原有
 增）   │                                               │ D35 → D49
        │                                               │ 下 → 上
        └───────────────────────────────────────────────┘
                    下长边（原有）D25 → D4F，左 → 右
```

| 编号 | 边 | 位置 | 丝印范围 | 方向 | 测得量 |
|---|---|---|---|---|---|
| **E0** | 长边（原有） | 下 | D25 → D4F | 左 → 右 | X |
| **E1** | 短边（原有） | 右 | D35 → D49 | 下 → 上 | Y |
| **E2** | 长边（新增） | 上 | D35 → D41 | 右 → 左 | X |
| **E3** | 短边（新增） | 左 | D35 → D3a | 上 → 下 | Y |

> **注**：D35 在多块裁剪板上重复出现是正常的 —— 它们是从同一张原板剪开的不同片段，位号沿用了原丝印。

## 二、接线方案

### 2.1 总原则

**四块转接板的 SDO 全部并联到 H11 第 2 脚（MISO）**，靠 4 根独立 CS 分时读取。

**EN1~EN4 四块板共用一组**（因为 CS 已保证唯一选中，无需每板独立 EN）。

### 2.2 信号分配表

| 信号 | 主控引脚 | 去向 | 说明 |
|---|---|---|---|
| **SPI4_SCK** | PE2 (AF5) | 四板 P4.2 | 并联 |
| **SPI4_MOSI / SDI** | PE6 (AF5) | 四板 P4.5 | 并联 |
| **SPI4_MISO / SDO** | PE5 (AF5) | 四板 SDO 焊盘 | **并联，H11.2** |
| **EN1** | PD13 | 四板 P4.6 | 并联共用 |
| **EN2** | PD12 | 四板 P4.7 | 并联共用 |
| **EN3** | PH11 | 四板 P4.8 | 并联共用 |
| **EN4** | PH10 | 四板 P4.9 | 并联共用 |
| **3.3V** | — | 四板 P4.1 | 并联 |
| **GND** | — | 四板 P4.10 | 并联 |

### 2.3 片选分配（需要新增 2 根）

| 板 | 边 | CS 引脚 | FPC | 状态 |
|---|---|---|---|---|
| **A** | E0 下长边 | **PI8** | FPC12 | 已有 |
| **B** | E1 右短边 | **PH4** | FPC16 | 已有 |
| **C** | E2 上长边 | **PI9**（建议） | 新 FPC | **待确认** |
| **D** | E3 左短边 | **PI10**（建议） | 新 FPC | **待确认** |

> **⚠️ 需你确认**：新增两块板的 FPC 插座编号，以及 C/D 用 PI9/PI10 是否与现有电路冲突。

### 2.4 为什么 EN 可以共用

```
时刻 t：只有 CS_A 为低，其余三块为高
        → 只有板 A 的 ADS7953 被使能
        → 板 A 的 SDO 驱动 MISO，其余三块高阻
        → EN1~EN4 同时到达四块板，但只有板 A 响应
```

**省下 8 根引脚，且四块板的行选严格同步（对定位一致性有利）。**

## 三、固件改造

### 3.1 板数量

```c
#define ADC64_BOARD_COUNT   4U      /* 由 2 改为 4 */
```

### 3.2 片选表

```c
static const cs_t k_cs[ADC64_BOARD_COUNT] = {
    { GPIOI,  8U },   /* E0 下长边 */
    { GPIOH,  4U },   /* E1 右短边 */
    { GPIOI,  9U },   /* E2 上长边  ← 待确认 */
    { GPIOI, 10U },   /* E3 左短边  ← 待确认 */
};
```

### 3.3 每条边的有效通道范围（可配置）

```c
typedef struct {
    uint8_t first_col;   /* 起始列索引（0~15） */
    uint8_t last_col;    /* 结束列索引 */
    uint8_t reverse;     /* 1 = 逆序输出 */
} edge_cfg_t;

/* 索引 i → 列 = i/4，行 = i%4 + 1 */
static const edge_cfg_t k_edges[4] = {
    { 5, 15, 0 },   /* E0 下长边：索引 21~63，顺向 */
    { 5,  9, 0 },   /* E1 右短边：索引 22~39，顺向 */
    { 5, 15, 1 },   /* E2 上长边：索引 21~63，逆向 */
    { 5,  9, 1 },   /* E3 左短边：索引 22~39，逆向 */
};
```

### 3.4 扫描时序

```
for 行 r = 0..3:
    EN(r) 置高，其余拉低
    等待 2 ms
    for 板 b = 0..3:
        CS(b) 拉低
        18 帧流水线读 16 通道
        CS(b) 拉高
```

**单帧耗时**：4 行 × 4 板 × 18 帧 × ~75 µs ≈ **22 ms**（不含行建立）
**含行建立**：4 × (2 ms + 5.4 ms) ≈ **30 ms** → **33 Hz**

## 四、屏幕定位算法（200 × 100 mm）

### 4.1 核心思想：双冗余交叉定位

**每条轴有两块独立的边：**

```
X 轴：下长边 E0  +  上长边 E2     → 两个独立估计 X₀、X₂
Y 轴：右短边 E1  +  左短边 E3     → 两个独立估计 Y₁、Y₃
```

**融合策略：**

```
X = (X₀ × w₀ + X₂ × w₂) / (w₀ + w₂)
Y = (Y₁ × w₁ + Y₃ × w₃) / (w₁ + w₃)

权重 w = 该边的总光强（越亮越可信）
```

**三重收益：**

| 收益 | 说明 |
|---|---|
| **精度提升** | 两边独立测量，加权平均后噪声降 √2 |
| **故障检测** | `|X₀ − X₂|` 过大 → 某条边异常，可报警 |
| **盲区补偿** | 光斑靠近某条边时，对面那条边仍有信号 |

### 4.2 坐标映射

```
屏幕宽 = 200 mm，高 = 100 mm

X_mm = (X_index / (n_X − 1)) × 200
Y_mm = (Y_index / (n_Y − 1)) × 100
```

**其中 `X_index` 是重心（亚探测器精度），`n_X` 是该边的探测器数。**

> **注意**：同一条长边的探测器间距不再是 4.8 mm，而是 `200 / (n_X − 1)`。
> 若探测器实际间距仍为 4.8 mm，则该边只覆盖部分屏幕宽度，
> **需在标定时测量实际覆盖长度**。

### 4.3 入射角

沿用几何法，但因为现在**两个轴都有冗余**，可以同时给出 θx 与 θy：

```
θx = atan((X − X_peak) / L)
θy = atan((Y − Y_peak) / L)

θ  = atan(sqrt(tan²θx + tan²θy))     /* 合成倾角 */
```

**这样单自由度的伺服可以选一个轴控制，另一个轴只做监视。**

## 五、UI 重设计

### 5.1 布局

```
┌────────────────────────────────────────────────────────────────┐
│ 端口 COM5 [连接][断开][标定]                        已连接     │
├────────────────────────────────────────────────────────────────┤
│                        上长边 E2（13 点）                       │
│                    ▁▂▃▅█▇▅▃▂▁▁▁                                │
│   ┌────────────────────────────────────────────────────┐       │
│ 左│                                                    │右     │
│ 短│                                                    │短     │
│ 边│              ┌─────────┐                          │边     │
│ E3│              │θx=+2.1° │                          │E1     │
│   │        ●─────┤θy=-1.4° │                          │       │
│  █│       光点   │X=98.4   │                          │█      │
│  █│              │Y=51.2mm │                          │█      │
│  █│              └─────────┘                          │█      │
│   │                                                    │       │
│   └────────────────────────────────────────────────────┘       │
│                    ▁▂▃▅█▇▅▃▂▁▁▁                                │
│                        下长边 E0（43 点）                       │
├────────────────────────────────────────────────────────────────┤
│ 位置 X= 98.4  Y= 51.2 mm   θx=+2.1° θy=-1.4°  一致性 98%      │
└────────────────────────────────────────────────────────────────┘
```

### 5.2 关键改进

| 项 | 当前（两边） | 新设计（四边） |
|---|---|---|
| 边数 | 2 | **4** |
| 光点位置 | 单边重心 | **双轴冗余融合** |
| 角度 | 只有 θ | **θx + θy + 合成** |
| 一致性指示 | 无 | **\|X₀−X₂\| 归一化 → 0~100%** |
| 布局 | 底部 + 右侧 | **四边包围矩形，更贴近实物** |

### 5.3 一致性指标

```
一致性 = 100% × (1 − |X₀ − X₂| / 200)
```

- **> 95%** → 绿：两条边测量吻合，数据可信
- **85~95%** → 黄：有偏差，可能是光斑靠近某侧
- **< 85%** → 红：某条边异常，需检查接线
