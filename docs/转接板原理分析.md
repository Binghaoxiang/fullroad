# 转接板（ADC64）原理分析

> 来源：`ADC64 for mcu g.PcbDoc` 的 OLE 流解析（Components6 / Nets6 / Texts6）。
> 标注 **[确定]** = 网络表/位号直接读到；**[推断]** = 由数量和连接关系推出来的，需原理图或实测确认。

---

## 1. 板上一共只有 29 个器件

| 位号 | 器件 | 说明 |
|---|---|---|
| **U1** | **ADS7953** | 12 位、16 通道、1 MSPS SAR ADC，SPI 接口 **[确定，丝印 `ads7953tssop`]** |
| **U2** | **74HC245** | 八路总线缓冲器（TSSOP20），只单向使用 **[确定，丝印 `74HC245(Tssop20)`]** |
| **P3** | `connector20` | 20 脚，**模拟侧** |
| **P4** | `connector10-1.0` | 10 脚 1.0mm FPC，**数字侧** |
| R0 ~ Rf | 16 只 0402 电阻 | 每个模拟通道一只 |
| R17 / R18 | 10K | 分压/上拉 **[推断：构成基准分压]** |
| R19 | 1K | 串阻 |
| C102 ~ C106 | 1uF ×3、100nF ×2 | 电源滤波 |
| L1 | PB1608-221/2A | 磁珠，隔离模拟/数字电源 |

**注意**：整块板**没有运放、没有多路开关、没有基准芯片**——
说明模拟前级（光电二极管 + 负载电阻）在探测器板上，这块板只负责"选通 + 数字化"。

---

## 2. 网络名就是它的全部功能

```
CH0 CH1 … CHF       16 路模拟输入
EN1 EN2 EN3 EN4     4 路行选输出
NCS SCLK SDI SDO    SPI 四线
REF                 基准
3.3V GND            电源
NetP4_2 … NetP4_9   P4 上 7 个信号（接 245 的 MCU 侧）
NetC105_2 / NetC106 P4 电源附近电容的节点
```

---

## 3. 关键设计一：74HC245 只缓冲"7 根单向线"，SDO 直连

这是这块板最值得讲的地方。

P4 是 10 脚，但需要 8 个信号，看起来"不够用"。实际分配是：

```
P4 脚 1   : 3.3V
P4 脚 2,3,5,6,7,8,9 : 7 根 → 74HC245 → 内部信号   ← NetP4_2/3/5/6/7/8/9（正好 7 个！）
P4 脚 4   : SDO ← 直连 ADC，不经缓冲
P4 脚 10  : GND
```

**为什么 SDO 不缓冲？**

| 信号方向 | 是否缓冲 | 原因 |
|---|---|---|
| NCS / SCLK / SDI / EN1~EN4（主控 → 板） | **缓冲** | 长排线引入的干扰/ESD 由 245 挡在 ADC 之外；245 驱动能力也比 ADC 引脚强 |
| **SDO（板 → 主控）** | **不缓冲** | ADS7953 的 SDO 本身就是**三态输出**（CS 高时高阻），可以直接驱动长线；再过一级 245 反而多一个方向控制问题 |

**关键**：74HC245 的 DIR 是一个引脚控制全部 8 个通道的方向，**不能一半进一半出**。
所以设计者只能让 245 单向工作（7 根全部是"主控 → 板"），
把唯一需要反向的 SDO 单独引出来 —— 这就是 P4 只有 7 个 `NetP4_x` 网络的原因。

> **对你现在的接法的影响（好消息）**：
> 两块板的 **SDO 是 ADC 的三态输出直连**，并联到一根 MISO 上完全没问题；
> 而 **EN1~EN4 是两块板各自 245 的独立输出**（输出端各接各的探测器），
> 并联的只是 P4 侧的输入，不存在两个输出对打。✔

---

## 4. 关键设计二：这块板还是"行选驱动器"

`EN1~EN4` 不是从探测器板来的，而是**从 MCU 经 P4 进来、过 245、再送到 P3** 去驱动探测器矩阵的行：

```
MCU ──PC0..PC3──► P4 ──► 245 ──► EN1..EN4 ──► P3 ──► 探测器板的行线
```

这意味着：**矩阵的选通时序完全由 MCU 控制，ADC 板只做驱动和数字化**。
好处是 4 次扫描的节奏可以任意调整（比如只扫有探测器的行、或加快某一行）。

---

## 5. 关键设计三：基准 REF 与满量程

板上有 REF 网络，但**没有基准芯片**，只有 R17/R18（各 10K）。

**[推断]** R17、R18 把 3.3 V 分压成 **1.65 V** 作为 ADC 基准（`REF = 3.3V/2`），
R19（1K）+ C105/C106 做 RC 滤波。

**这对读数的意义**：如果 REF = 1.65 V，那么

```
码值 4095  →  1.65 V（不是 3.3 V！）
每 1 LSB = 1.65V / 4096 ≈ 0.40 mV
```

所以量电压时：`V = code × 0.40 mV`。这个数值要在标定时确认一次
（用万用表量 REF 脚对地电压，除以 4096 就是 LSB）。

---

## 6. 其它细节

| 设计 | 作用 |
|---|---|
| **R0~Rf 每通道一只** | 输入限流/负载电阻。光电二极管的光电流经过它转成电压，再进 ADC。**不要动它的阻值**，否则增益和带宽全变 |
| **L1 磁珠 + C102~C106** | 把 ADC 的数字噪声挡在模拟电源之外（1uF 储能 + 100nF 高频旁路） |
| **P3 20 脚** | 16 路模拟 + 4 路行选，正好对应探测器板的 CH0~CHF 与 EN1~EN4 |
| **P4 10 脚** | 3.3V + GND + 7 根单向信号 + SDO |

---

## 7. 一次完整采集的电气过程

```
① MCU: EN_r 拉高（经 245 送到探测器板的第 r 行）
        ↓ 300 µs 等模拟通路稳定（光电二极管电流经 R0~Rf 建立电压）
② MCU: CS 拉低 → 选中这块板的 ADS7953
③ MCU: 连发 16 个 SCK，同时 SDI 上送 4 位通道地址
        ADS7953 在 SCK 沿上采样该通道，把 12 位结果放到 SDO
④ MCU: 读回 16 bit → 高 4 位通道回显 + 低 12 位结果
⑤ MCU: CS 拉高 → SDO 回到高阻（此时另一块板可以安全地占用同一根 MISO）
```

**这就是为什么 CS 必须严格互斥**：第 ⑤ 步之前，被选中的板一直在驱动 SDO；
如果这时另一块板的 CS 也拉低，两块会同时对驱动同一根线。

---

## 8. 一句话总结

这块转接板 = **"16 路模拟前端 + 行列地址驱动 + SPI 数字化"三合一**：

- **模拟**：16 路经 R 进 ADS7953，REF 由 3.3V 分压得到；
- **选通**：MCU 送来的 4 路 EN 经 245 驱到探测器矩阵；
- **数字化**：16 位 SPI 帧读出，SDO 三态输出可多板共享；
- **缓冲**：245 只保护 7 根"主控 → 板"的单向线，SDO 例外。

理解了这三点，固件里 `adc64.c` 的 `en_on(row)` → `read_frame(col)` 循环
就是这套硬件原理的直接翻译。
