# 光学膜自动对准（舵机自适应追踪）方案 v0.1

> 目标：激光倾斜照射光学膜时，舵机自动旋转，使激光**垂直（法线方向）**入射到光学膜上。
> 判据来自光学膜**四周端面的红外探测器**。

---

## 1. 需求还原与物理理解

```
            激光（倾斜入射，角度 θ）
                     \
                      \  ← 需要把 θ 调到 0
        ┌──────────────────────────────┐
   探测器│       光学膜（50 寸）          │探测器
   (左)  │    光在膜内形成十字型光路       │(右)
        │                              │
        └──────────────────────────────┘
           探测器(下)        探测器(上)
                     ↑ 舵机（控制膜的角度）
```

- 激光打在膜上 → 膜内出现**十字型光路**，四条臂分别射向四个端面
- 四个端面各装红外探测器 → 得到 4 路（或 4 组，每组 16 路）光强
- 舵机转动 → 改变膜与入射光的夹角 θ
- **控制目标**：把 θ 调到 0（激光垂直入射）

### 1.1 关键物理性质（决定控制算法）

设四个方向的光强为 `L, R, T, B`（左/右/上/下），入射倾角为 `θx, θy`：

| 量 | 定义 | 对称性 | 用途 |
|---|---|---|---|
| **差值信号** `Sx = (L-R)/(L+R)`、`Sy = (T-B)/(T+B)` | 归一化差 | 关于垂直入射**奇对称**，θ=0 处过零 | **锁零**（精调），零点附近增益大 |
| **总光强** `P = L+R+T+B` | 总和 | 关于垂直入射**偶对称**，θ=0 处取极大 | **捕获**（粗调），远处单调可爬坡 |
| 归一化 | 除以总和 | 不受激光功率/距离波动影响 | 必须做 |

> 所以控制律要**两段式**：
> **① 用 P 爬到山顶（捕获）→ ② 用 S 锁零（精调）**。
> 只用 P：山顶附近太平坦，精度差；只用 S：远处没有方向信息，可能爬错方向。

> ⚠ 上述奇/偶对称是"对称膜结构"的理想结论。实际膜有个体差异，
> **符号和零点偏移必须在台架上标定一次**（见 §6）。

### 1.2 结构特点带来的两条约束

1. **50 寸膜 + 舵机 = 大惯量、有回程差、会振荡** → 控制带宽只能做到 **0.5~2 Hz**。
2. 因此**不要用连续 PID**，而用**"步进-稳定-测量-决策"的准静态闭环**：
   - 走一小步（0.2°~1°）
   - 等结构稳定（200~500 ms，可测）
   - 采 100~1000 次求平均（把噪声压到 1/10~1/30）
   - 算新误差 → 决定下一步（梯度/Nelder-Mead/黄金分割）
   - **单向逼近**：始终从同一侧接近目标，规避回程差

## 3. 控制状态机

```
        ┌────────┐  P < 阈值           ┌──────────┐
        │  IDLE  │ ──────────────────► │  SEARCH  │ 全行程慢扫，记录 P 曲线
        └────────┘                     └──────────┘
             ▲                              │ 找到 P 的峰
             │ P 长时间 < 阈值               ▼
        ┌────────┐  |S| 大              ┌──────────┐
        │  LOST  │ ◄─────────────────── │  COARSE  │ 爬坡（每次 0.5°，看 P 是否上升）
        └────────┘                      └──────────┘
             ▲                              │ P 上升 < 1%/步
             │                              ▼
        ┌────────┐  |S| < 死区            ┌──────────┐
        │  LOCK  │ ◄─────────────────── │   FINE   │ 步长 0.05°~0.1°，S 过零即停
        └────────┘ ─────────────────────►└──────────┘
             稳定 1~2 s 或 S 越界 → 回 FINE
```

| 状态 | 进入条件 | 动作 | 退出条件 |
|---|---|---|---|
| `IDLE` | 上电/手动 | 输出保持，等待 `TRK ON` | 收到命令 |
| `SEARCH` | 无有效光强 | 在 `LIM` 行程内慢扫（10°/s），记录 P−θ 曲线 | 找到峰 |
| `COARSE` | 有光但 P 未最大 | 步长 0.5°，沿 P 增大方向走 | P 增量 <1% 或到峰顶 |
| `FINE` | 接近峰顶 | 步长 0.05~0.1°，用 Sx/Sy 判断方向 | `|S| < S_dead` |
| `LOCK` | 已锁零 | 不再动，只监视 | S 越界 / P 掉 20% → FINE/COARSE |
| `LOST` | 光消失超时 | 保持最后角度，报警 | 光恢复 → COARSE |

**死区与滞环**：`S_dead ≈ 0.5%`（进）、`2%`（出），避免在零点附近来回抖（limit cycle）。

## 4. 控制律（可直接落代码）

### 4.1 每轴独立 + 交替迭代（单舵机时）
单舵机通常只有 1 个轴。若机构能同时影响两轴，则**交替迭代**：先调 X 轴到 |Sx| 最小，再调 Y 轴，重复 2~3 轮（两轴耦合弱时收敛很快）。

### 4.2 准静态步进（推荐，抗振荡）
```
step = clamp(K * S,  step_min, step_max)      // K ≈ 0.5~2 °/单位S
θ_new = θ + sign_corrected(step)              // 符号由标定给出
servo_set_angle(θ_new);  wait_settle(300ms);  measure_avg(200);
```
- `step_max` 限制单步不超过 1°（大惯量结构一次走太多会过冲）
- `step_min` = 0.05°（对应 PWM 约 1.1 个 LSB，0.5 µs/LSB）
- 每步都**从同一方向逼近**目标，消除回程差

### 4.3 连续 PI（可选，仅用于最后的微动）
`ω = Kp*S + Ki*∫S dt`，输出角速度限制 ≤ 2°/s。
仅在 `|S| < 5%` 且结构已稳定时启用；一旦发现振荡立即退回准静态。

### 4.4 有效性判据（防止把噪声当信号）
```
有效 = (P > P_dark * 3) && (P 在最近 5 次测量中的波动 < 10%) && (单路不饱和)
```
不满足则视为"无光"，进入 SEARCH/LOST。

## 5. 分阶段实施计划

| 阶段 | 内容 | 验收标准 | 预估 |
|---|---|---|---|
| **M1 采集通路** | 打通探测器→MCU 的信号链；`DBG RAW` 输出原始值；暗电流扣除 | 遮光时 ≈0±噪声；照明时有稳定读数、不饱和 | 2~3 天 |
| **M2 曲线（最关键）** | 手动 `+/-` 点动扫一遍，同时记录 `S`/`P` → 画出 θ–S 和 θ–P 曲线 | 曲线单调、过零明确；据此定下方案 A 还是 B | 1~2 天 |
| **M3 单轴闭环** | SEARCH/COARSE/FINE/LOCK | 初始偏差 ±5° 内 <3 s 锁定；静态误差 <0.1° | 3~5 天 |
| **M4 鲁棒性** | 断光/复光、笔移动、功率衰减、振动 | 连续 30 min 不失锁（笔固定时） | 3~5 天 |
| M5 双轴（后续） | 加第二条边/第二个舵机时的扩展 | — | 视需求 |

**每个阶段都先在上位机波形里看数据，再改算法**——不要盲调。

## 6. 标定流程（一次性，每台设备）

1. **暗电流标定**：关激光，采 2000 次求均值 → `offset[i]`（红外探测器有暗电流 + 环境光本底）
2. **通道增益归一化**：均匀照明（或把膜摆正、让十字对称），记录各路均值 → `gain[i] = mean/mean_i`
3. **符号标定**：手动把舵机 +0.5°，看 `Sx` 是变正还是变负 → 决定控制器的符号
4. **零点偏移（null offset）**：膜本身不对称时，`S` 的过零点不在 θ=0 → 记录 `S0`，控制时用 `S - S0`
5. **行程与安全边界**：`L/W/T` 命令设定角度和脉宽范围，避免撞限位
6. （可选）**P–θ 曲线**存档，作为 SEARCH 的先验

## 7. 抗干扰要点（红外系统的老问题）

| 干扰 | 现象 | 对策 |
|---|---|---|
| 日光灯 100 Hz 纹波 | S 上叠加 100 Hz | 采样窗口取 100 Hz 的整数倍（10 ms/20 ms）；或软件陷波 |
| 环境光缓变 | 零点慢漂 | 每次测量前扣一次"当前本底"（快门/断光法）或做长期高通 |
| 激光功率波动 | P 抖动 | 用归一化 S（已解决 P 的影响） |
| 探测器饱和 | P 削顶 | 检查 `V < 0.9*Vref`，必要时减增益 |
| 舵机回程差 | 来回走同一角度位置不同 | 单向逼近 + 超时重标 |

**根治办法（可选）**：激光加**调制**（比如 1 kHz 方波），探测器做**同步解调（锁相放大）**，可把环境光完全压掉。这会让信噪比提升 1~2 个数量级，强烈建议在 M5 之后考虑。

## 8. 遥测与调参（很重要，直接影响调试效率）

建议每 20 ms 输出一行，方便用 **VOFA+ / 串口波形助手**直接画曲线：

```
$S,1234,1198,1201,1230,0.0146,-0.0092,4863,45000
  └L   R    T    B   Sx      Sy      P   θ(毫度)
```

配上这些调试命令：

| 命令 | 作用 |
|---|---|
| `TRK ON/OFF` | 开/关自动追踪 |
| `TRK?` | 打印状态机当前状态、Sx/Sy、P、角度、锁定时间 |
| `CAL DARK` | 采暗电流 |
| `CAL GAIN` | 采增益归一化 |
| `CAL SIGN` | 自动判定符号（转一小步看 S 变化方向） |
| `STEP <deg>` | 单轴开环点动（复用已有 `+/-`） |
| `DBG RAW` | 直接输出原始 4/64 路数据 |

## 9. 主要风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 4 路信号区分度不足（十字四条臂都亮） | 无法判断倾斜方向 | 用 16 通道分组（每端面 16 个探测器的**质心**代替总光强），信息量大得多 |
| 膜的非对称性导致 S 零点偏离垂直 | 系统性偏差 | 零点偏移标定（§6.4）；或用 P 峰值作为绝对参考校正 S 零点 |
| 大惯量 + 回程差 | 振荡、精度差 | 准静态步进 + 单向逼近（§4.2） |
| 舵机是连续旋转型（速度控制） | 无法定角度 | 用积分速度模式：`∫ω dt` 作为虚拟角度，仍在 SEARCH 中找峰 |
| 长时间锁定时结构温漂 | 缓慢失锁 | LOCK 状态下持续监视 S，超阈值自动微调 |

## 10. 已确认约束（v0.2 更新）

| 项 | 结论 | 对方案的影响 |
|---|---|---|
| 探测器 | **目前只有一条边**，先用一条边模拟 | 见 §11，控制律要改成"单边版" |
| 舵机 | **1 轴** | 单自由度，不需要解耦，M3 即可完成 |
| 精度 | **0.1°** | 对应 50 寸膜边缘 ≈2.2 mm；0.5 µs PWM(0.045°) 够用，靠多次平均 |
| 光源 | **激光笔**（连续光） | 不能锁相放大；功率/位置会抖，必须靠归一化 + 平均 + 稳定性判据 |

### 10.1 剩余待确认

1. **那条边上到底有几个探测器？** 1 个 → 只能用"强度爬坡"（§11.2 方案 B）；
   ≥2 个 → 可以左右分半做**差分**（§11.1 方案 A，强烈优先）。
2. **探测器波长范围**：激光笔是 **650 nm 红光**。
   - Si 光电二极管（400~1100 nm）→ 能响应，可以直接模拟 ✅
   - InGaAs（900~1700 nm）→ **对 650 nm 基本无响应**，模拟不出来 ❌
   请确认型号，这一条不对，后面全部白做。
3. 探测器输出是**模拟电压**（需要 MCU ADC / 外部 ADC），还是板上已经数字化？

## 11. 简化版：单边 + 单轴（当前阶段）

只有一条边有探测器时，能拿到的东西比四边少，但**单轴 0.1° 仍然做得成**，
关键是选对控制模式。

### 11.1 方案 A：单边左右分半 → 差分锁零（优先）

把这条边上的 N 个探测器按位置分成左半 / 右半两组：

```
      ┌──────────────────────────────┐
      │        光学膜                 │
      └──┬───┬───┬───┬───┬───┬───┬───┘
         D1  D2  D3  D4  D5  D6  D7        ← 同一条边的探测器
         └── 左半组 ──┘   └── 右半组 ──┘

  S = (Σ左 − Σ右) / (Σ左 + Σ右)      归一化 -> 与激光功率无关
  P = Σ左 + Σ右
```

- 膜左右倾斜时，光斑沿这条边**横移** → `S` 变号 → **θ=0 处过零**
- 优点：方向信息明确、零点附近增益大、抗功率波动
- 要求：舵机轴必须对应"光斑沿边横移"的方向（M2 台架确认）

### 11.2 方案 B：单路强度 → 抖动爬坡（兜底）

如果这条边只有 1 个探测器，`P(θ)` 是**偶对称**（θ=0 处峰值），没有方向信息，
就用**扰动观察法（dither）**：

```
每步：走 +Δ 测 P1 → 走 -2Δ 测 P2 → 比较
   P1 > P2  → 继续 +
   P1 < P2  → 改为 -
   |P1-P2| < 噪声 → 认为到顶，锁
```

- 优点：只要有强度就能工作
- 缺点：慢（每步 3 次测量）、顶部平坦处判据弱、需要一个"上次方向"记忆防止抖动
- 步长建议 Δ = 0.3°，噪声门槛取 3σ

> **推荐先按方案 A 实现（代码里做成可切换），方案 B 作为只有单路时的兜底。**

### 11.3 单边的固有局限（必须知道）

**单边无法区分"膜在倾斜"和"激光笔在平移"** —— 两者都会让光斑沿边移动。
所以：
- 台架验证阶段：**激光笔必须固定在支架上**，只动舵机
- 现场使用：光笔移动时控制器会"追"过去，这是正常的（它追的是光斑位置），
  但会牺牲垂直度；若要严格分离，必须再加一条**平行边**做共模抑制

### 11.4 激光笔的额外处理

| 问题 | 现象 | 对策 |
|---|---|---|
| 手抖/笔移动 | S 一直抖，锁不住 | 进入 LOCK 前要求"S 连续 5 次波动 < 2%"；LOCK 后超阈值才重捕 |
| 功率波动（电池衰减） | P 缓慢下降 | S 已归一化；P 的阈值用**相对值**（与上电初值比）而非绝对值 |
| 光斑跳动（多模激光笔） | P 有 10~30% 随机跳变 | 每次测量取 200 次平均；用中值代替均值抗离群 |
| 650 nm 不好对准 | 看不见光路 | 建议台架阶段换成可见光 + 荧光卡辅助定位，或直接用 850 nm 激光模组 |
