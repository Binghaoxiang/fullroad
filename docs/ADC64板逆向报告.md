## 2. 网络名（这就是信号定义）

| 网络 | 含义 |
|---|---|
| `CH0`~`CH9`、`CHA`~`CHF` | **16 路模拟输入**（十六进制编号） |
| `NCS` | SPI 片选（低有效） |
| `SCLK` | SPI 时钟 |
| `SDI` | SPI 数据入（ADC 接收命令字） |
| `SDO` | SPI 数据出（ADC 回传转换结果） |
| `EN1`~`EN4` | 4 路使能 |
| `3.3V` / `GND` / `REF` | 电源 / 地 / 基准 |
| `NetP4_2`~`NetP4_9` | P4 第 2~9 脚（未命名，接 245 与内部） |

## 3. 原理框图（推断）

```
   16 路探测器（每路一个限流电阻 R0~Rf）
        │
        ▼
   ┌───────────┐   REF (基准)
   │ ADS7953   │◄── 3.3V / GND
   │ 16ch ADC  │
   └─────┬─────┘
         │ CS / SCLK / SDI / SDO  （4 线 SPI）
         ▼
   ┌───────────┐
   │ 74HC245   │  缓冲/电平驱动
   └─────┬─────┘
         │ 10pin FPC (P4)
         ▼
   主控板 FPC 槽  →  STM32F429 的 SPI4 / SPI5 / SPI1
```

**64 通道 = 4 块这样的板**（每块 16 通道），与主控板上
`SPI4_CS0~CS4`、`SPI5_CS0~CS4`、`SPI1_CS0~CS2` 共 13 个独立片选对应。
`EN1~EN4` 正好是 4 组使能，与"4 块板"的分组一致。

## 4. 主控板侧的 SPI 资源（已核对原理图网络表）

| SPI | SCK | MISO | MOSI | CS → 对应 FPC 槽 |
|---|---|---|---|---|
| SPI4 | PE2 | PE5 | PE6 | CS0~CS4 → FPC16/15/14/13/12 |
| SPI5 | PC10 | PC11 | PC12 | CS0~CS4 → FPC11/10/9/8/7 |
| SPI1 | PA5 | PA6 | PA7 | CS0~CS2 → FPC1/2/3 |
| SPI6 | — | — | **无 MOSI** | CS0~CS2 → FPC6/5/4 |

每个 FPC 槽的引脚定义：

| FPC 脚 | 信号 |
|---|---|
| 1 | +3V3 |
| 2 | SPIx_SCK |
| 3 | SPIx_CSn |
| 4 | SPIx_MISO |
| 6~9 | 模拟通道（01~04 等） |
| 10~12 | GND |

## 5. ⚠ 一个必须先确认的矛盾点

**FPC 槽只引出了 SCK / CS / MISO 三根，没有 MOSI（SDI）。**

- SPI4/SPI5/SPI1 的 MOSI 网络（PE6 / PC12 / PA7）在原理图上**只连到 MCU 自己**，没有连到任何 FPC 或排针；
- 而 **ADS7953 必须通过 SDI 送 4bit 通道地址命令字**才能选通道。

所以只有三种可能：

| 可能 | 特征 | 验证方法 |
|---|---|---|
| (a) 板上 SDI 被固定接法（例如接地/接高），ADC 工作在固定通道序列 | 能读但要靠 CS 次序推断通道 | 逻辑分析仪抓 SDI 有无波形 |
| (b) 需要从 MCU 的 PE6/PC12/PA7 单独飞一根到 ADC 板 SDI | 只读模式不成立 | 看 P4 第 5 脚是否真有连线到 SDI |
| (c) 这块板只用 CS+SCK 做"移位输出"（245 当移位器），不用 ADS7953 的 SPI 模式 | 时序与手册不符 | 实测波形 |

**没有原理图就无法断定**，但这决定了固件是"标准 ADS7953 驱动"还是"自定义时序"。

## 6. 对固件的影响

现在的 `sensor.c` 是按"模拟电压进 MCU 内部 ADC（PC0~PC3）"写的。
如果探测器走的是这块 ADC 板，则必须改成 **SPI 读 ADS7953**：

- 每通道 1 帧 16 bit（高 4 位通道地址 + 12 位数据）
- 一次测完 16 通道 → 求 `S`、`P`（`track.c` 的状态机不用改，只换数据源）
- 4 块板 = 4 个 CS，用同一个 SPI 外设轮流读
