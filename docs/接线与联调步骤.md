# 两条边（长边 + 短边）+ 两块 ADC64 + 主控 接线与联调

> 依据：`pin64-307-2835.PcbDoc`（探测器板）、`ADC64 for mcu g.PcbDoc`（采集板）、
> `ProPrj_50寸主控026-09-21.epro`（主控板）逆向结果。
> **两条边 = 两块 ADC64 采集板**，各占一个 SPI。

---

## 1. 探测器板编号规律

64 只光电二极管，**4 行 × 16 列**，十六进制位号：

```
D<行><列>     行 = 1..4（EN1..EN4）    列 = 0..F（CH0..CHF）
```

| 行 | 位号 | 使能 |
|---|---|---|
| R1 | D10 … D1F | EN1 |
| R2 | D20 … D2F | EN2 |
| R3 | D30 … D3F | EN3 |
| R4 | D40 … D4F | EN4 |

每只串一个 SOD523（`S<行><列>`），形成 **行选 + 列读** 的 4:1 复用：
同一时刻只有一行导通，4 次扫描才能读完 64 个点。

> 你剪断后每条边剩下哪几行/哪几列，**不要推算，用第 6 步实测确认**。

---

## 2. 两块 ADC64 板的接口

### P4（10 脚 FPC）= 数字侧
```
NCS  SCLK  SDI  SDO  EN1  EN2  EN3  EN4  3.3V  GND
```

### P3（20 脚）= 模拟侧
```
CH0 … CHF   REF   3.3V  GND       ← 接对应那条边的探测器列线
```

⚠ P4 没有丝印标号，接线前**必须万用表确认**：
① 与大面积地相通的 = GND；② 与 U1（ADS7953）电源脚相通的 = 3.3V。

---

## 3. 完整接线表（两块板，SDO 并联 + 双 CS）

> **SDO 并联是标准做法**：ADS7953 的 SDO 在 CS 为高时呈高阻，只有被选中的那块
> 才驱动数据线，所以 SCK / SDI / SDO 三根共享，靠 CS 分时选通。
> ⚠ **两块板的 CS 任何时刻只能拉低一个**，同时为低会两边对驱动 → 总线冲突（可能烧片子）。
> 固件里每帧只拉低一个 CS 并在帧末立即释放，天然互斥。

### 共用 3 根（两块板并联）

| 信号 | 主控 STM32F429 | 接两块板的 |
|---|---|---|
| SCLK | **PE2**（SPI4_SCK） | SCLK |
| **SDO → MISO** | **PE5**（SPI4_MISO） | SDO（两块并联） |
| SDI ← MOSI | **PE6**（SPI4_MOSI） | SDI（两块并联） |

### 各自独立的 1 根

| 板 | 片选 | 主控 |
|---|---|---|
| 板 A（长边） | NCS | **PE3** |
| 板 B（短边） | NCS | **PE4** |

### 共用 4 根行选

| 信号 | 主控 |
|---|---|
| EN1 / EN2 / EN3 / EN4 | **PC0 / PC1 / PC2 / PC3** |

### 电源

| 信号 | 说明 |
|---|---|
| 3.3V | 两块板都要接 |
| GND | 两块板都要接，且与主控共地 |

**合计 9 根信号线 + 3.3V/GND。** 舵机仍在 PD12（TIM4_CH1）。

## 4. 掩码（屏蔽剪断的死点）

固件对**每块板**各有一个 64 位掩码，`bit = 行*16 + 列`，1 = 计入求和。
默认全 1（全部计入）。

```
K MASKA <hex64>    ← 板 A（长边）
K MASKB <hex64>    ← 板 B（短边）
```

用途：剪断后某些点恒为 0 或噪声大，把它们对应 bit 清 0 即可，避免影响 S。

例：只保留 R3、R4 两行（行索引 2、3）：

```
K MASKA FFFFFFFF00000000
```

（行 2 的 bit = 32..47，行 3 的 bit = 48..63 → 高 32 位为 1）

---

## 5. 固件的判定逻辑

```
S = (长边 A 之和 − 短边 B 之和) / (长边 A 之和 + 短边 B 之和) × 1000     （千分比）
P = 两块板全部光强之和

S 在激光垂直入射处过零  → 锁零（模式 A）
P 在激光垂直入射处取极大 → 捕获（模式 B）
```

跟踪状态机（SEARCH / SEEK / LOCK / LOST）与舵机控制沿用原有实现。

## 6. 联调步骤

### 第 1 步：断电检查
两块板分别量 P4 的 GND↔3.3V 不能短路（不能是 0 Ω）。

### 第 2 步：只接电源
两块板 3.3V + GND，上电，各量 3.3 V（±0.1）。

### 第 3 步：接两块板的 SPI（EN 暂不接）
发 `K RAW`，应看到**两段矩阵**（`# A long` 和 `# B short`），全部是 200~800 的本底。

| 现象 | 原因 |
|---|---|
| A 正常、B 全 0 | 板 B 的 SPI/CS 没接好（PC10/PC11/PC12/PE4） |
| 都全 0 | 两块共用的地没接 |
| 全 4095 | 该板的 SDI/SDO 接反（对调） |
| 乱跳 | 降速：`ADC64_SPI_BR` 由 4 改 6（/128） |

### 第 4 步：接 EN 并校准行对应
两块板的 EN1~EN4 并联到 PC0~PC3。激光笔照**板 A 某一列**的一只探测器，然后：

```
K EN 1 ; K RAW
K EN 2 ; K RAW
K EN 4 ; K RAW
K EN 8 ; K RAW
```

哪一次亮在 R1/R2/R3/R4，就说明 EN 编号与行的对应关系；
若错位，把接线的 EN 线换位即可。

### 第 5 步：标定本底
完全遮光 → `K DARK`

### 第 6 步：确认两条边各自的响应
- 激光笔照**长边**的探测器 → `K RAW` 里 `A=` 明显增大；
- 照**短边** → `B=` 明显增大。
- 记下每条边实际还活着的 (行, 列) 范围，把死点用 `K MASKA/MASKB` 屏蔽。

### 第 7 步：扫曲线定模式/方向
```
K CURVE -3 3 0.3        ← 输出角度,S,P 的 CSV
K A 或 K B              ← 按曲线形态选
K SIGN 1 / K SIGN -1    ← 试一下方向
```

### 第 8 步：闭环
```
K ON
K                       ← 看到 ST=LOCK 即成功
```

## 7. 常见问题

| 现象 | 处理 |
|---|---|
| 只有一条边有数据 | 检查另一块板的 SPI 四线 + CS |
| S 一直是 0 或满量程 | 两条边信号量级差异过大，先分别看 A、B 的值 |
| 闭环来回抖 | 增大 `TRK_S_DEADBAND`、`TRK_SETTLE_MS` |
| 越追越远 | `K SIGN` 翻转 |
| 某列恒 0 | 该列线在剪断时被切断，用掩码屏蔽 |
